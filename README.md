# Personal Website
Personal website, blog, and landing pages for my projects.

## Overview
This repository contains the source code for my personal website. It serves as:

- Personal homepage
- Development blog
- Landing pages for mobile and web applications
- Public documentation such as privacy policies

The site is intentionally built with plain HTML with Bootstrap v5 for simplicity.

## Structure
```text
/
├── index.html         # Homepage
├── about/             # About page
├── posts/             # Blog posts
└── projects/          # Projects' landing pages
```

## Tech Stack
- HTML
- Bootstrap v5
