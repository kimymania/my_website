RootMi

A co-operative chord sheet editor for musicians and bands

RootMi is a collaborative music tool that allows band members to create, edit, and share chord sheets in real time. It is designed for both practice sessions and live performances, supporting offline use and seamless synchronization when online.

What RootMi does

RootMi helps musicians work together on song arrangements using simple chord-based sheets.

  • Create chord sheets for songs
  • Edit and annotate sheets using touch or stylus input
  • Share sheets with band members
  • Collaborate in real time during rehearsals or live sessions
  • Automatically transpose chords into different musical keys
  • Access and edit sheets even without an internet connection
  • Switch between light and dark mode according to your preference

Key Features

Offline-first editing

Works reliably even in rehearsal environments with limited connectivity.

Chord-based system

Simple chord sheets instead of full music notation for quick editing.

Setlists

Create, store and edit entire setlists for a session.

Handwriting & drawing

Annotate sheets using stylus or touch input.

Auto transpose

Instantly change key for any song arrangement.

Cloud sync

Store and share chord sheets across devices.

Real-time collaboration

Edit together during live sessions and rehearsals.

Data Collection & Usage

RootMi collects minimal user data to provide core functionality.

Email address

Used for authentication, password recovery, and important service-related notifications.

User content (chord sheets)

Stored securely to enable syncing and collaboration. Shared only when explicitly chosen by the user.

We do not sell user data or use it for advertising purposes.

Purpose of Data Usage

  • User authentication and account security
  • Real-time collaboration features
  • Storage and synchronization of chord sheets
  • Essential account and service notifications
